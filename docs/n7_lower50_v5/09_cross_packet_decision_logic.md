# v5 Module 09 — cross-packet decision logic

## X-01 — Maintain independent packet ledgers

Do not infer Packet-A closure from Packet-B structure or vice versa.  Record
the exact unresolved component in each lane after every theorem promotion.


**Decisive output:** A two-row live frontier.

## X-02 — Search for a shared multi-degree invariant

Compare the B2 quiver centralizer and Packet-A refined Koszul modules.  A
shared invariant is retained only if it yields one concrete theorem in both
packets.


**Decisive output:** One cross-packet lemma or a stop decision.

## X-03 — Use target-torus weights consistently

Align row/column character conventions across Packet A, Packet B, and the
universal bypass.  Add a negative control for reversed coefficient transport.


**Decisive output:** A common weight dictionary.

## X-04 — Prevent survivor scope inflation

A slice, tangent, projected, or local module survivor must never be labelled a
49-term endpoint survivor.  Define exact required fields for a complete
survivor.


**Decisive output:** A survivor schema.

## X-05 — Choose the shortest lower-50 proof path

If the universal bypass succeeds, stop packet-specific closure for theorem
promotion.  If one packet closes first, concentrate resources on the other
rather than expanding the closed proof.


**Decisive output:** An updated dependency minimum.

## X-06 — Assemble cross-packet adversarial controls

Run every final lemma against local Packet-B survivors, Glynn49, Glynn64,
non-tensor Sylvester equality, and abstract extension countermodels as
appropriate.


**Decisive output:** A final control table.

## X-07 — Freeze one exact unresolved theorem if promotion fails

If lower 50 remains open, the package must end with one or two formal theorem
statements, not a list of exploratory experiments.


**Decisive output:** `ONE-EXPLICIT-GAP` or `TWO-INDEPENDENT-GAPS`.

## X-08 — Decide the lower-50 package

Return exactly `LOWER-50-PROMOTABLE`, `EXACT-ENDPOINT-SURVIVOR`, or
`LOWER-50-REMAINS-OPEN-AT-EXPLICIT-GAP`.


**Decisive output:** One terminal package status.
