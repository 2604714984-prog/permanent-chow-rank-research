# v5 Module 05 — Packet-A refined Koszul program

## AK-01 — Define the automatic subcomplex to quotient out

Formalize the plain catalectic/apolar-induction component in degrees `2/5` and
`3/4` and quotient it from every proposed refined operator.  A candidate whose
rank is determined by the automatic subcomplex is rejected before computation.


**Decisive output:** An automaticity test shared by all Packet-A candidates.

## AK-02 — Inventory nonautomatic representation components

List Koszul–Young, recursive-Koszul, exterior, Pluecker, and cross-weight
components compatible with degree seven and the 49-variable ambient space.
Identify their source/target representations and factor-coordinate formulas.


**Decisive output:** A finite candidate list, not all possible Schur functors.

## AK-03 — Filter by theoretical lower-50 capacity

Using exact one-term upper bounds and target-dimension upper bounds, discard
every component that cannot distinguish 49 from 50 even under optimistic
target rank.


**Decisive output:** A short candidate list with explicit inequalities.

## AK-04 — Reconcile with the existing 343-pair capacity audit

Prove which candidates are standard higher-wedge maps already covered, which
are nonnegative direct sums, and which are genuinely recursive or quotient
components.  Do not rename an exhausted map.


**Decisive output:** A no-duplication theorem.

## AK-05 — Reconcile with Chow-specific Koszul–Young equations

Translate the relevant Chow secant equations into the repository's labelled
factor-subproduct conventions.  State whether they concern ordinary or border
rank and whether they survive the Packet-A endpoint quotient.


**Decisive output:** Exact map identification and scope.

## AK-06 — Define the first recursive-Koszul candidate

Construct a two-stage differential whose intermediate homology retains
term-labelled factor incidence and is not determined by the ordinary
catalectic factorization.


**Decisive output:** A basis-independent map with bounded block structure.

## AK-07 — Compute the one-term rank-seven cap

In factor coordinates compute the exact rank/homology contribution of one
product of seven independent linear forms.  Prove basis invariance and cover
factor-rescaling boundaries.


**Decisive output:** An exact one-term cap.

## AK-08 — Compute the permanent target rank by torus blocks

Exploit row/column symmetry and weight decomposition to compute the actual
target rank without materializing the ambient exterior-symmetric matrix.
Modular discovery must end in a characteristic-zero certificate.


**Decisive output:** Exact target rank and block inventory.

## AK-09 — Compute the 49-term endpoint defect threshold

Compare the target rank with 49 one-term caps and determine the exact positive
rank or homology defect required to exclude Packet A.


**Decisive output:** A numerical theorem target, not an empirical ratio.

## AK-10 — Incorporate the simple multilinear matroid

Determine whether pairwise transverse factor seven-planes force additional
independence between one-term refined images.  State the gain as a theorem,
not as generic position.


**Decisive output:** A matroid-conditioned cap or collision lemma.

## AK-11 — Construct the relative Koszul homology

Quotient derivative-generated/apolar-induced cycles and retain only homology
which depends on the same seven factors across degrees.  Compute its target
value for the permanent.


**Decisive output:** A nonautomatic relative invariant.

## AK-12 — Test recursive depth two

If one stage is insufficient, compose exactly one further recursive step.
Preflight source/target sizes and stop before a general recursive framework.


**Decisive output:** A depth-two decision.

## AK-13 — Split the refined map by permanent weights

Find the smallest row/column torus blocks carrying positive target defect.
The same term coefficients and factor coordinates must appear across blocks.


**Decisive output:** A theorem-facing small-block formulation.

## AK-14 — Apply mandatory controls

Glynn49 must fail at a known target block, Glynn64 must pass every universal
identity it should satisfy, and the non-tensor Sylvester example must prevent
a false tensor-split conclusion.


**Decisive output:** Exact pass/fail control matrix.

## AK-15 — Search only theorem-defined boundary strata

If the main block is generically obstructed, classify rank-drop boundaries
created by the proof.  Do not open broad factor-coordinate searches.


**Decisive output:** A finite boundary list.

## AK-16 — Promote finite calculations to characteristic zero

Use exact rational rank, integer minors, representation-theoretic rank
formulas, or controlled modular lifts.  Agreement of several primes is
diagnostic only.


**Decisive output:** A compact exact certificate.

## AK-17 — Extract a refined Packet-A obstruction

Prove that every point of the active `W^all != 0`, `K2,K5 != 0` component has
positive refined defect, or freeze an exact component with zero defect.


**Decisive output:** `A-REFINED-OPERATOR-HAS-POSITIVE-ENDPOINT-DEFECT` or an exact survivor.

## AK-18 — Decide the refined-Koszul lane

If every shortlisted map is automatic or has capacity below 50, publish a
route-ceiling theorem and transfer priority to Modules 06–07.  Do not continue
by adding arbitrary representations.


**Decisive output:** `AK-CLOSED`, `AK-SURVIVOR`, or `AK-ROUTE-CEILING`.
