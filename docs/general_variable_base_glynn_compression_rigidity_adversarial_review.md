# Adversarial review: variable-base Glynn rigidity

## Is this the unrestricted six-block problem?

No. Every atom still uses one fixed split into `m-2` shared columns and two tail
columns, and both the shared and tail forms come from the Glynn sign family.
Atoms may choose different deleted bases, but they may not choose different
column splits or arbitrary linear forms.

## Does the lower bound assume a common deleted base?

No. The common base is a consequence at equality. The initial dictionary
contains every ordered pair `C_(v,u)` with `v!=u`.

## Where is the key rigidity?

The shared tensors `U_v` have exactly one relation. Grouping by source sign
therefore leaves one common tail correction `Z`. Every absent source forces the
same `Z` to equal a different `-B_v`, so at most one source can be absent.

## Could equality use a different base for each source?

No. Equality leaves one atom per retained source. The tail rank-one points have
no collinear triples, forcing every atom to use the unique omitted source as
its base.

## Strict conclusion

The theorem classifies the whole variable-base fixed-split sign dictionary. It
does not prove `mu(6,4)=7`, does not change ordinary Chow rank or border rank,
and makes no literature-novelty claim.
