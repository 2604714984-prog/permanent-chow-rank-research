## Stop rules

Suspended unless a theorem reopens them:

- larger scalar derivative/shadow dynamic programs;
- more uncoupled Koszul sweeps;
- blind enlargement of curve boxes;
- random-point nonexistence claims;
- unit-weight-only Packet-B classification;
- unrestricted `GL_6` searches;
- broad mixed-Glynn enumeration not forced by B2;
- full construction of all 84 Hilbert strata before structural reduction;
- generic initials used without transforming the target;
- exact-64 engineering before the 49-term endpoint is decided;
- new managers, databases, schedulers, registries, or evidence platforms.

A workstream stops on an exact survivor satisfying all encoded hypotheses.

## Substantive progress

Counts:

- deciding an entire `q5` class;
- closing a complete frontier triple;
- a target-only theorem valid for multiple triples;
- an exact target/coupling survivor;
- proving or falsifying common-code reduction;
- an exhaustive B2 branch theorem;
- a nonzero Packet-A defect;
- closing Packet A or Packet B;
- promoting lower 50.

Does not count alone:

- another agreeing prime;
- a larger empty random sample;
- prettier code for an existing rank test;
- exclusion of an unforced restricted family;
- a formal Hilbert/Betti inventory with no target consequence;
- unrelated infrastructure.

Preferred: a fully audited ordinary characteristic-zero lower-50 theorem.

Second: an exact 49-term endpoint survivor identifying the missing invariant.

Third: one endpoint packet closed and the other reduced to one explicit
theorem-defined component.

outcomes triggers route re-evaluation rather than more search volume.
