# Bootstrapping general permanent Chow-rank bounds from the derivative tower

## Status and claim boundary

`PROOF_DRAFT_COMPLETE`, `GENERAL_N_THEOREM`,
`EXACT_INTEGER_REPLAYED`.

This note composes two already proved general ingredients:

1. the permanent-relative derivative-tower capacities `B_(n,d)(q)`; and
2. the complementary-intersection Koszul residual inequality.

The composition defines a lower-bound promotion operator valid for every
`n`. Its first new finite consequence is

\[
\boxed{\operatorname{ChowRank}(\operatorname{perm}_7)\ge 47.}
\]

For `n=7`, exact exhaustion also shows that the same named scalar
`tower + first-Koszul residual` bootstrap stabilizes at 47. This fixed point is
not an upper bound on the actual Chow rank and does not constrain other
invariants.

## 1. Inputs

Write

\[
P_n=\operatorname{perm}_n,
\qquad
E_d(n)=\mathcal D_d(P_n).
\]

For `q` degree-`n` Chow terms `T_1,...,T_q`, the derivative-tower theorem gives
an exact integer capacity `B_(n,d)(q)` satisfying

\[
\dim\left(
E_d(n)\cap\sum_{i=1}^{q}\mathcal D_d(T_i)
\right)
\le B_{n,d}(q).
\tag{1.1}
\]

The recurrence defining `B` uses exact permanent product shadows and a
section/projection inequality. It is valid for repeated or dependent factors
and makes no direct-sum assumption.

Choose a first-Koszul output degree

\[
2\le m\le n-2
\]

and put `r=n-m`. Define

\[
A_{n,m}
=
 n^2\binom nm^2-\binom n{m+1}^2
\tag{1.2}
\]

and

\[
K_{n,m}
=
 n^2\binom nm-\binom n{m+1}.
\tag{1.3}
\]

Here `A_(n,m)` is the Koszul rank of `P_n`, while one Chow term contributes at
most `K_(n,m)`.

The complementary-intersection residual theorem states that, for any form
`R`,

\[
\operatorname{rank}K_m(P_n-R)
\ge
A_{n,m}-n^2 b,
\tag{1.4}
\]

where

\[
b=\dim\left(E_r(n)\cap\mathcal D_r(R)\right).
\]

The output-side intersection and the catalectic rank cancel; only the
complementary derivative-space intersection remains.

## 2. The promotion operator

For an integer `L>=1`, define

\[
\begin{aligned}
\Phi_n(L)=\max\Bigg\{L,\;
\max_{\substack{2\le m\le n-2\\1\le q\le L}}
\left[
q+
\left\lceil
\frac{A_{n,m}-n^2B_{n,n-m}(q)}{K_{n,m}}
\right\rceil_+
\right]
\Bigg\},
\end{aligned}
\tag{2.1}
\]

where

\[
\lceil x\rceil_+=\max\{0,\lceil x\rceil\}.
\]

### Theorem 2.1 -- general tower bootstrap

If

\[
\operatorname{ChowRank}(P_n)\ge L,
\]

then

\[
\boxed{
\operatorname{ChowRank}(P_n)\ge\Phi_n(L).
}
\tag{2.2}
\]

### Proof

Let an arbitrary Chow decomposition of `P_n` contain `R` nonzero terms. The
hypothesis gives `R>=L`. Fix any legal `m` and `q<=L`, and select any `q` terms;
call their polynomial sum `Q`.

For the actual coupled sum, only the containment

\[
\mathcal D_r(Q)
\subseteq
\sum_{i=1}^{q}\mathcal D_r(T_i)
\tag{2.3}
\]

is used. Therefore (1.1) gives

\[
\dim\left(E_r(n)\cap\mathcal D_r(Q)\right)
\le B_{n,r}(q).
\tag{2.4}
\]

Apply (1.4):

\[
\operatorname{rank}K_m(P_n-Q)
\ge
A_{n,m}-n^2B_{n,r}(q).
\tag{2.5}
\]

The residual `P_n-Q` is the sum of the remaining `R-q` Chow terms. Rank
subadditivity and (1.3) give

\[
(R-q)K_{n,m}
\ge
A_{n,m}-n^2B_{n,r}(q).
\]

If the right side is nonpositive this adds no information. Otherwise integer
rounding gives

\[
R\ge
q+
\left\lceil
\frac{A_{n,m}-n^2B_{n,r}(q)}{K_{n,m}}
\right\rceil.
\]

Maximizing over all legal `m,q` proves (2.2). ∎

### Corollary 2.2 -- iterated closure

Starting from any valid lower bound `L_0`, define

\[
L_{j+1}=\Phi_n(L_j).
\tag{2.6}
\]

Every `L_j` is a valid lower bound. The sequence is nondecreasing and consists
of integers bounded above by the actual Chow rank, hence it stabilizes.

A fixed point closes only the inference system generated by (1.1) and (1.4).
It does not prove that the actual rank equals the fixed point.

## 3. Exact `n=7` tower closure

The global first-Koszul bound is

\[
L_0=36.
\]

The exact adjacent derivative tower was rebuilt through degree five and
through 47 terms. The decisive capacities are

\[
B_{7,4}(20)=341,
\tag{3.1}
\]

\[
B_{7,5}(36)=233,
\qquad
B_{7,5}(39)=267,
\tag{3.2}
\]

\[
B_{7,5}(46)=405,
\qquad
B_{7,5}(47)=426.
\tag{3.3}
\]

### First promotion: `36 -> 46`

At output degree `m=3`, complementary degree `r=4`, and `q=20`,

\[
A_{7,3}=58,800,
\qquad
K_{7,3}=1,680.
\]

Using (3.1),

\[
58,800-49\cdot341=42,091,
\]

and

\[
20+\left\lceil\frac{42,091}{1,680}\right\rceil
=20+26=46.
\tag{3.4}
\]

The exhaustive scan has four maximizers and no larger candidate, so

\[
\Phi_7(36)=46.
\]

### Second promotion: `46 -> 47`

Now use output degree `m=2`, complementary degree `r=5`, and all `q=46`
selectable terms. One has

\[
A_{7,2}=20,384,
\qquad
K_{7,2}=994.
\]

By (3.3),

\[
20,384-49\cdot405=539>0.
\tag{3.5}
\]

Thus a hypothetical 46-term decomposition would leave the zero residual after
all 46 terms were selected, while (3.5) would force its second-output Koszul
rank to be at least 539. Equivalently, (2.1) gives

\[
46+\left\lceil\frac{539}{994}\right\rceil=47.
\]

The exhaustive scan has eight maximizers and no larger candidate, hence

\[
\boxed{\Phi_7(46)=47.}
\]

Therefore

\[
\boxed{
\operatorname{ChowRank}(\operatorname{perm}_7)\ge47.
}
\tag{3.6}
\]

Glynn supplies the independent upper bound 64.

### Fixed point at 47

Every output degree `m=2,3,4,5` and every fixed count `1<=q<=47` was checked.
The maximum candidate is 47. In particular, at the endpoint

\[
A_{7,2}-49B_{7,5}(47)
=20,384-49\cdot426
=-490,
\]

so the all-term contradiction has disappeared. The exact closure is

\[
\boxed{
36\longmapsto46\longmapsto47\longmapsto47.
}
\tag{3.7}
\]

This is a route fixed point, not an exact-rank theorem.

## 4. Why this is a general-`n` result

The operator `Phi_n` is defined for every `n` and accepts any valid external
lower bound as input. A finite instance is used only to verify the theorem,
produce a real unrestricted improvement, and identify the point at which the
current scalar mechanism stops.

The exact `n=7` fixed point is useful negative information: continuing to
re-evaluate the same tower and first-Koszul residual inequalities cannot prove
48. A proof beyond 47 must strengthen at least one input, for example by

- reducing a tower capacity through Chow-realizability geometry;
- adding a non-scalar multigraded or representation-valued defect;
- replacing first-Koszul residual rank by a stronger compatible map; or
- deriving a recurrence linking different values of `n`.

## 5. Hidden assumptions and strongest objection

### Hidden assumptions

1. Selecting `q` terms is legal only after an independent lower bound `L>=q`
   has been proved.
2. `B_(n,r)(q)` controls the literal derivative-space sum. The coupled sum
   enters only by containment (2.3).
3. The residual inequality uses the complementary degree `r=n-m`, not the
   Koszul output degree `m` unless the split is self-transpose.
4. A fixed point of `Phi_n` is a proof-route boundary, not an upper bound on
   rank.

### Strongest objection

The entire operator is still scalar: it remembers dimensions of derivative
spaces and exact shadow cardinalities, but not the representation type or the
relations coupling different terms. Therefore its fixed point may be far
below `2^(n-1)`. The `n=7` value 47 versus the Glynn upper bound 64 confirms
that this objection is material.
