# N6-081: the first strict shortening of the \(b=34\) layer

**Status.** PURE_B34_FIRST_SHORTENING; EXACT_INTEGER_STATE_REPLAY.

## 1. Statement

In the \(N=28\) maximal-middle-rank branch, fix six terms and retain the
twenty-two residual terms. Put

\[
 S=E_3\cap G_3,\qquad \dim S\ge 400-34=366.
\]

For a residual set \(A\), write

\[
 U_i=\mathcal D_3(T_i),\quad L_A=\sum_{i\in A}U_i,\quad
 f_A=\dim(S\cap L_A),\quad x_A=\dim(E_3\cap L_A).
\]

Then either every residual seven-set satisfies \(f_A\le 79\), or some
seven-set is forced into the exact endpoint

\[
 x_A=f_A=80,\quad \dim\partial X_A=90,\quad
 \varepsilon_i=0,\quad \alpha_i=3,\quad \kappa_2=0
 \tag{1.1}
\]

for all seven colors. Its seven quadratic \(15\)-planes are literal direct,
their quotient images are one common \(W_{15}\), and six anchored section
differences span the \(90\)-plane \(\partial X_A\).

## 2. Universal seven-set bounds

The seven-term omitted-factor projection bound is

\[
 \dim\left(E_2\cap\sum_{i\in A}F_i\right)\le 15(7-1)+3=93.
 \tag{2.1}
\]

The exact product-shadow DP gives

\[
 m_{80}=90,\qquad m_{81}=96.
 \tag{2.2}
\]

Since

\[
 \partial(E_3\cap L_A)\subseteq E_2\cap\sum_{i\in A}F_i,
\]

we have \(x_A\le 80\), hence \(f_A\le 80\).

For a residual fifteen-set \(B\), let \(C=B^c\). The map from \(S\) to the
quotient by \(L_C\) has kernel \(S\cap L_C\), and its image is generated by
\(L_B\). Therefore

\[
 \dim L_B\ge \dim S-f_C\ge 366-80=286.
\]

If \(A\subset B\) has seven elements, the remaining eight terms contribute
at most \(8\cdot20\), so

\[
 \dim L_A\ge 286-160=126.
 \tag{2.3}
\]

## 3. The equality packet

Assume \(f_A=80\). Then \(X_A=S\cap L_A=E_3\cap L_A\) has dimension \(80\).
Its shadow is at least \(90\), leaving omitted-factor defect at most three.
Using the proved termwise implication

\[
 \varepsilon_i>0\Longrightarrow \alpha_i\ge 2,
\]

the exact relation envelope has eleven states. Existing \(t_2\le 14\)
prolongation caps exclude ten. The sole survivor is

\[
 \varepsilon=(0,\ldots,0),\qquad \kappa_2=0,\qquad
 d_2=105,\qquad t_2\le 15.
 \tag{3.1}
\]

The seven \(F_i\) are literal direct. If \(\sum_i u_i=0\), with \(u_i\in U_i\),
then differentiation gives a relation in \(\bigoplus_iF_i\). Every derivative
of each \(u_i\) vanishes, so \(u_i=0\) in characteristic zero. Hence

\[
 \dim L_A=7\cdot20=140.
\]

If any \(\varepsilon_i=0\) term had \(\alpha_i\le 2\), the \(t_2=15\) cap
would be \(458\), but

\[
 E_3+L_A\subseteq\left(E_2+\sum_iF_i\right)^{(1)},\qquad
 \dim(E_3+L_A)=400+140-80=460.
\]

Thus every \(\alpha_i=3\). Each \(q(F_i)\) has dimension \(15\), equal to the
total quotient dimension, so

\[
 q(F_1)=\cdots=q(F_7)=W_{15},\qquad a_2=105-15=90.
\]

The sum-zero kernel of seven copies of \(W_{15}\) has dimension \(90\);
it equals \(\partial X_A\) and is spanned by the six anchored differences.

## 4. Boundary

This is a strict alternative, not an exclusion of either branch. It does not
exclude global \(b=34\), prove
\(\operatorname{ChowRank}(\operatorname{perm}_6)\ge 29\), or make a
border-rank claim.
