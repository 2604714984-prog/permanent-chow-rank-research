## 1. Hidden assumption: coordinate columns are not arbitrary matrix columns

The proof uses the special derivative rule

```text
partial_(i,j) p_(R,C) = p_(R-i,C-j)
```

and the fact that each nonzero derivative column is one coordinate vector.
This is true for the subpermanent basis of `D_4(perm_8)`.  It would be false
for a generic basis or a generic catalecticant, so the finite union-find model
cannot be detached from this basis identity.

## 2. Tangent criterion

At a point where the derivative map has exact rank `784`, the tangent space to
the rank-at-most-`784` locus is characterized by sending the old kernel into
the old image.  The quotient formulation

```text
D_phi|ker(mu_0)=0
```

is standard and correct.  Because `mu_0` has coordinate columns, its kernel is
generated by zero columns and differences of equal nonzero columns.  The
finite equations used by the script are therefore complete.

## 3. Finite enumeration boundary


Grassmann graph variables.  The zero-column rule leaves `8,960`; the remaining
identifications produce one zero component of size `2,240` and twenty-seven

## 4. Second-order formula

Write the image near the reference point as the graph of a map from the old
image `B` to a complement `C`.  Expanding the graph equation gives the mixed
obstruction

```text
psi_alpha D_B^beta + psi_beta D_B^alpha
```

modulo maps that factor through the old derivative map.  A second-order
Grassmann correction contributes only such a factor-through term, so the
quotient class is intrinsic.  Self-obstructions vanish because every basic
direction is explicitly integrated.

## 5. Characteristic-zero equation rank

The finite reconstruction yields only 256 distinct integer quadrics.  Their
coefficient matrix has rank 256 modulo `1,000,003`; therefore its rank over
`Q` is at least 256.  The explicit row count gives the equal upper bound.  No
finite-field equality is promoted without that upper bound.

The modular rank does not prove the set-theoretic classification.  That part
is supplied separately by the closed formulas for the 203 monomials and 53
binomials.

## 6. Zero-locus classification

The same-column monomials and `2 x 2` permanents force the ambient `6 x 2`
matrix to have at most one nonzero source row; the analogous equations do the
same for the low-line `4 x 2` matrix.  The cross equations then give exactly:

```text
four 4-planes
eight 3-planes
seven lines.
```

This argument is set-theoretic.  It does not claim that the quadratic ideal is
radical or that the full local determinantal ideal has no embedded structure.

## 7. Integration and the dimension argument

The elementary-replacement lemma proves the shadow dimensions over every
characteristic-zero field and for every parameter value in the graph chart.
It is not a finite-sample inference.  The tensor-intersection formula uses the
actual inclusions

```text
partial(ell) subset partial(Q)
partial(H) subset R_3.
```

Thus all nineteen linear spaces occur in the actual tangent cone.

The equality locus is projective and torus-stable.  Every irreducible
component contains a fixed point, and the multiplicity-free torus weights make
fixed Grassmann points coordinate.  The prior coordinate theorem classifies
all such points.  Hence the maximum local tangent-cone dimension four is a
global upper bound; the integrated four-parameter families give equality.

## 8. Strongest remaining objection

The theorem does not prove that every noncoordinate equality component is one
of the closures of the nineteen displayed families.  A nonlinear component
may have the same leading tangent plane, and distinct formal branches may
share one tangent-cone component.  The correct next task is to restrict the
fourteen-term Chow incidence to the four top-dimensional branches, not to
promote the tangent result into a full equality-locus classification.
