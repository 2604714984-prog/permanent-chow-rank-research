# Ledger delta: exceptional-source criterion

Add the following general coordinate second-order reduction.

A target matching outside all one-factor envelopes has zero second-order
coefficient whenever every capable active source is an injective, exactly
pairwise source whose relevant intermediate tangent monomials are absent from
the initial source image and tangent to no other active source.

Thus every coordinate second-order survivor must be covered by at least one of

```text
TRIPLE_SOURCE
SOURCE_JET_ABSORPTION
TANGENT_COLLISION
INTERNAL_FIBER
```

for each target outside the one-factor envelope union.

This is a necessary-filter theorem, not a construction or unrestricted zero
theorem. `mu(6,4)` remains open in `[6,8]`.
