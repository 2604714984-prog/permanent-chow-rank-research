# Ledger delta: source-jet elimination outside the one-factor envelope

For a target matching outside every one-factor envelope, each intermediate
monomial on a two-factor path already contains three target edges. It therefore
cannot lie in any initial coordinate frame. `SOURCE_JET_ABSORPTION` is
impossible for such a target.

Combined with the `C6` source-multiplicity cap and distinct factors, a
collection of distinct `C6` equality-frame types can survive the current
second-order criterion only through `TANGENT_COLLISION`.

This is a necessary reduction. General coordinate second-order lifts and
`mu(6,4)` remain open.
