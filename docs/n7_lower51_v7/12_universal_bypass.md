# v7 Module 12 — universal bypass invariant

A short direct lower-51 proof is preferred if one genuinely coordinate-invariant coupled map covers every packet.

## UX-01 — compare all surviving branches

Search for one common residual or circuit property shared by rank-seven, rank-six, and low-rank packets.

**Decisive output:** `UNIVERSAL-COMMON-DATA`.

## UX-02 — derive a branch-independent connecting map

Formulate it without choosing a direct basis when possible.

**Decisive output:** `UNIVERSAL-CONNECTING-MAP`.

## UX-03 — compute the permanent demand

Determine the exact target rank or homology class of the universal map.

**Decisive output:** `UNIVERSAL-TARGET-DEMAND`.

## UX-04 — compute one-term caps

Prove caps for all factor ranks and dependent-factor degenerations.

**Decisive output:** `UNIVERSAL-ONE-TERM-CAPS`.

## UX-05 — test subadditivity

Reject maps whose rank or defect cannot be summed over Chow terms.

**Decisive output:** `UNIVERSAL-SUBADDITIVITY`.

## UX-06 — test coordinate invariance

Reject invariants dependent on a row-normal or graph chart not forced by the identity.

**Decisive output:** `UNIVERSAL-INVARIANCE`.

## UX-07 — test all known countermodels

Include Glynn64, scalar surplus saturation, common-factor circuits, and abstract extension models.

**Decisive output:** `UNIVERSAL-CONTROLS`.

## UX-08 — derive a direct lower-51 ratio

If the target demand exceeds 50 one-term caps, assemble the shortest proof.

**Decisive output:** `UNIVERSAL-LOWER51`.

## UX-09 — derive a branch-reduction theorem

If the ratio is insufficient, use the invariant to force packets into fewer structural branches.

**Decisive output:** `UNIVERSAL-REDUCTION`.

## UX-10 — compare with packet-specific proofs

Retain the universal route only if it shortens at least two branch arguments.

**Decisive output:** `UNIVERSAL-VALUE-GATE`.

## UX-11 — freeze failure boundaries

Record exact counterexamples rather than repeatedly varying the same map.

**Decisive output:** `UNIVERSAL-BOUNDARY`.

## UX-12 — issue the bypass verdict

Return `UNIVERSAL-LOWER51`, `UNIVERSAL-REDUCTION`, or `UNIVERSAL-STOP`.

**Decisive output:** `UNIVERSAL-VERDICT`.
