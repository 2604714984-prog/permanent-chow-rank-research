# NGEN-02: inventory of theorem-bearing natural-map routes

This document is an exact index of existing frozen certificates.  It does not
recompute a large matrix and it does not introduce a new invariant.  Its
purpose is to keep four logically different facts separate:

1. an exact permanent rank;
2. an exact or modular one-term rank window;
3. a proved uniform cap for degenerate Chow terms; and
4. a restricted-family obstruction that cannot be promoted to unrestricted
   Chow rank.

The machine-readable certificate is
`data/general_natural_map_inventory.json`, generated by
`scripts/general_natural_map_inventory.py`.

## Route decision

No current entry satisfies all three promotion requirements:

\[
\text{coordinate-invariant map} + \text{uniform degenerate one-term cap}
+ \text{subadditivity under sums}.
\]

Therefore no new unrestricted lower bound is claimed from this inventory.  The
next theorem-bearing target is a cross-degree invariant retaining the coupled
derivative-module structure, with a proved one-term cap that survives arbitrary
linear changes of variables.

## Boundary

\(\operatorname{ChowRank}(\operatorname{perm}_6)\) and does not prove or
refute \(\operatorname{ChowRank}(\operatorname{perm}_n)=2^{n-1}\). The
separate theorem in `n6_exact_ordinary_chow_rank_32.md` now proves the exact
ordinary value 32 by a coupled quotient-symbol argument outside the route
table above. No border-rank conclusion follows from either document.
