## New theorem

For

```text
4 <= m <= n
q >= 2
q*n <= m^2+1
```

and arbitrary degree-`n` Chow terms `T_i`,

```text
D_m(perm_n) intersect sum_i D_m(T_i) = 0.
```

The new part is the first positive excess `q*n=m^2+1`; the strict and equality
cases are inherited.

The enlarged guaranteed zero-block size is

```text

```

when `m>=4` and `zeta_plus>=2`.
