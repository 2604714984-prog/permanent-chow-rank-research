# Adversarial review: source-jet elimination outside `E1`

The theorem concerns a target matching outside every one-factor envelope. It
does not eliminate source jets for targets already sharing three cells with an
initial frame.

The moved-away cell `e` is chosen from `Q minus M`, while the inserted cell `y`
is chosen from `M minus Q`. Therefore the intermediate monomial contains the
two cells of `Q cap M` and the target cell `y`, giving three distinct target
edges. This is the only fact needed.

The argument eliminates initial-source absorption but not cancellation by a
tangent of another active order-zero source. It also does not remove repeated
frame copies or repeated-factor source fibers outside the distinct `C6` family.

This is a necessary-filter theorem. It proves no construction, unrestricted
zero statement, ordinary-rank bound, border-rank bound, or novelty claim.
