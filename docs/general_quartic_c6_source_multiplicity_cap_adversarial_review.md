# Adversarial review: `C6` source-multiplicity cap

The cap concerns distinct labeled frame types. Repeating a frame type produces
additional branch occurrences of every source in that frame and can create a
triple-active source. The theorem records, rather than excludes, that mechanism.

The extension count is taken in the full `K_(4,4)`, not only inside a fixed
`3 x 3` block. A `P5` can choose either of two missing vertices on its smaller
bipartition side; the other two source shapes already determine their six
ambient vertices.

A four-edge source subset of a `C6` is necessarily acyclic. In particular a
`C4` source cannot occur because a six-cycle in a simple bipartite graph has no
four-cycle chord.

The theorem is only a source-incidence classification. Source-jet absorption
and cross-source tangent collisions remain possible, and no six-block zero,
ordinary-rank, border-rank, or novelty claim follows from the multiplicity cap
alone.
