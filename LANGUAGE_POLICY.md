# Repository language policy

All mathematical content committed to this repository must be written in English.

This includes:

- proof drafts and theorem statements;
- research notes and technical design documents;
- certificate specifications and audit reports;
- issue and pull-request descriptions that carry mathematical claims;
- code comments that explain mathematical semantics.

Source artifacts in another language may be referenced by immutable hash, but they are not copied into the active proof tree unless an English translation or English reviewer summary is supplied alongside them. Machine-generated data files may use language-neutral identifiers.
